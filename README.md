# Agrolandia

Il LANDI XL più vicino a te in un click, con gli orari e i prezzi del carburante AGROLA.
Sito e app (installabile dal browser): https://agrolandia.ch

Progetto volontario e amatoriale, senza scopi commerciali, non affiliato a LANDI, AGROLA o TCS.

I file di questo repository sono generati: la pagina si modifica nel progetto di lavoro e si copia qui
con `landi/strumenti/pubblica_pages.py`. Prezzi e orari si aggiornano ogni giorno.
